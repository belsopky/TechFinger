🎯 WHAT IS THIS?
════════════════════════════════════════════════════════════════════════════

TechFinger is a professional-grade technology fingerprinting tool for:
  • Penetration Testing Reconnaissance
  • OSINT on target infrastructure  
  • Portfolio/Research projects
  • Incident Response assessments

Unlike signature-based tools (Wappalyzer, BuiltWith):
  ✅ Shows WHY each technology was detected (confidence math)
  ✅ Detects contradictions (Apache + Nginx = reverse proxy hint)
  ✅ Correlates the full stack (CDN → Web Server → Framework → Frontend)
  ✅ Includes investigation paths for each technology
  ✅ No external databases (all rules embedded in source)
  ✅ Works offline, no API calls, no cloud dependencies

🚀 COMMON COMMANDS
════════════════════════════════════════════════════════════════════════════

# Fast scan (5 second timeout, no deep JS)
python3 techfinger.py -u https://target.com --profile fast

# Balanced scan (default: 10s timeout, 3 JS files)
python3 techfinger.py -u https://target.com

# Deep scan (30s timeout, 10 JS files, thorough)
python3 techfinger.py -u https://target.com --profile deep

# Show confidence math for every finding
python3 techfinger.py -u https://target.com --explain

# Generate Markdown report + export evidence
python3 techfinger.py -u https://target.com --report --evidence

# JSON output (for scripting/automation)
python3 techfinger.py -u https://target.com -o json > scan.json

# Compare two scans over time
python3 techfinger.py -u https://target.com --compare baseline.json

🎯 FEATURES AT A GLANCE
════════════════════════════════════════════════════════════════════════════

Detection:
  • Headers (Server, X-Powered-By, X-Generator, X-AspNet-Version, etc.)
  • Cookies (PHPSESSID, sessionid, laravel_session, jwt, etc.)
  • HTML DOM (React, Vue, Angular, Bootstrap, Tailwind, Next.js, etc.)
  • JavaScript Globals (window.React, window.gtag, etc.)
  • Error Pages (Django, Flask, Laravel, ASP.NET, Spring Boot, etc.)
  → 1,000+ total technology fingerprints

Confidence Scoring:
  • Reliability-weighted evidence (1.0 to 0.25 multipliers)
  • Bonus points for multiple evidence types
  • Version extraction bonus
  • Contradiction penalties
  • Final confidence 0-100%

Output:
  • Rich terminal tables (colored, formatted)
  • Confidence breakdowns (--explain flag)
  • Markdown report (--report flag)
  • JSON export (-o json)
  • Evidence directory (--evidence flag)
  • Scan comparison (--compare)

✅ REQUIREMENTS
════════════════════════════════════════════════════════════════════════════

• Python 3.11 or newer (3.12 tested ✓)
• pip (usually comes with Python)
• Linux/Kali Linux (also works on macOS, Windows with WSL)

No external APIs. No cloud services. No paid subscriptions.

Install dependencies:
  pip install -r requirements.txt

That installs:
  • requests (HTTP client)
  • beautifulsoup4 (HTML parsing)
  • rich (terminal rendering)

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Q: "ImportError: No module named 'requests'"
A: pip install requests beautifulsoup4 rich

Q: "SSL Certificate Verification Failed"
A: Update certificates: sudo update-ca-certificates --fresh

Q: "Connection Timeout"
A: Increase timeout: python3 techfinger.py -u <url> --timeout 30

Q: "Command not found: techfinger"
A: Use full path: python3 techfinger.py (or make it executable)

For more help, see INSTALL_KALI.md

📊 WHAT YOU GET
════════════════════════════════════════════════════════════════════════════

After running techfinger.py, you'll see:

1. Confidence Tiers (High/Medium/Low)
   • Technology name
   • Category (Web Server, Framework, Language, etc.)
   • Version (if detected)
   • Risk level (High/Medium/Low)
   • Evidence count
   • Confidence % (0-100%)

2. Stack Correlation
   • Likely technology chain visualized
   • CDN → Web Server → Language → Framework → Frontend

3. Contradictions (if found)
   • Conflicting evidence highlighted
   • Reverse proxy hints
   • Confidence penalties applied

4. Security Observations
   • Missing CSP/HSTS headers
   • Insecure cookie flags
   • Version leaks
   • Severity ratings

5. Investigation Paths
   • Per-technology next steps
   • Common misconfigurations
   • Suggested CVE checks

💡 TIPS & TRICKS
════════════════════════════════════════════════════════════════════════════

# Parse results with jq (JSON)
python3 techfinger.py -u <url> -o json | jq '.technologies[] | select(.confidence >= 70)'

# Find high-risk technologies
python3 techfinger.py -u <url> -o json | jq '.technologies[] | select(.risk == "High")'

# Batch scan multiple targets
for target in site1.com site2.com site3.com; do
  python3 techfinger.py -u https://$target -o json > $target.json
done

# Use with Burp Suite proxy
export HTTPS_PROXY="http://127.0.0.1:8080"
python3 techfinger.py -u https://target.com
