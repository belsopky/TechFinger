TechFinger v0.1.0
=================

Heuristic technology fingerprinting for penetration testers and security researchers.

What is TechFinger?
-------------------

TechFinger identifies web technologies using embedded heuristic rules. It analyzes HTTP headers, cookies, HTML, JavaScript, and server behavior to produce transparent, evidence-based results.

Unlike signature-based tools, TechFinger:
- Shows why each technology was detected (confidence math)
- Detects contradictions (e.g., Apache + Nginx suggests a reverse proxy)
- Correlates the full stack (CDN -&gt; Web Server -&gt; Framework -&gt; Frontend)
- Includes investigation paths for each technology
- Uses no external databases (all rules embedded in source)
- Works offline with no API calls

Quick Start
-----------

1. Clone:
   git clone https://github.com/HaQtor/TechFinger.git
   cd TechFinger

2. Install:
   pip install -r requirements.txt

3. Run:
   python3 techfinger.py -u https://example.com

Common Commands
---------------

# Fast scan (5 second timeout, no deep JS)
python3 techfinger.py -u https://target.com --profile fast

# Balanced scan (default: 10s timeout, 3 JS files)
python3 techfinger.py -u https://target.com

# Deep scan (30s timeout, 10 JS files)
python3 techfinger.py -u https://target.com --profile deep

# Show confidence math for every finding
python3 techfinger.py -u https://target.com --explain

# Generate Markdown report and export evidence
python3 techfinger.py -u https://target.com --report --evidence

# JSON output for scripting
python3 techfinger.py -u https://target.com -o json &gt; scan.json

Features
--------

Detection:
- HTTP Headers (Server, X-Powered-By, X-Generator, X-AspNet-Version, etc.)
- Cookies (PHPSESSID, sessionid, laravel_session, JWT, etc.)
- HTML DOM (React, Vue, Angular, Bootstrap, Tailwind, Next.js, etc.)
- JavaScript Globals (window.React, window.gtag, etc.)
- Error Pages (Django, Flask, Laravel, ASP.NET, Spring Boot, etc.)
- Session Patterns

Confidence Scoring:
- Reliability-weighted evidence
- Bonus points for multiple evidence types
- Version extraction bonus
- Contradiction penalties
- Final confidence 0-100%

Output:
- Rich terminal tables
- Confidence breakdowns (--explain)
- Markdown report (--report)
- JSON export (-o json)
- Evidence directory (--evidence)

Troubleshooting
---------------

Q: ImportError: No module named 'requests'
A: pip install requests beautifulsoup4 rich

Q: SSL Certificate Verification Failed
A: sudo update-ca-certificates --fresh

Q: Connection Timeout
A: Increase timeout: python3 techfinger.py -u &lt;url&gt; --timeout 30

Q: Command not found: techfinger
A: Use full path: python3 techfinger.py

For more help, see INSTALL_KALI.md.

Scan Output
-----------

After running techfinger.py, you will see:

1. Confidence Tiers (High/Medium/Low)
   - Technology name
   - Category (Web Server, Framework, Language, etc.)
   - Version (if detected)
   - Risk level (High/Medium/Low)
   - Evidence count
   - Confidence percentage (0-100%)

2. Stack Correlation
   - Likely technology chain: CDN -&gt; Web Server -&gt; Language -&gt; Framework -&gt; Frontend

3. Contradictions
   - Conflicting evidence highlighted
   - Reverse proxy hints
   - Confidence penalties applied

4. Security Observations
   - Missing CSP/HSTS headers
   - Insecure cookie flags
   - Version leaks
   - Severity ratings

5. Investigation Paths
   - Per-technology next steps
   - Common misconfigurations
   - Suggested manual checks

Tips
----

Parse results with jq:
  python3 techfinger.py -u &lt;url&gt; -o json | jq '.technologies[] | select(.confidence &gt;= 70)'

Find high-risk technologies:
  python3 techfinger.py -u &lt;url&gt; -o json | jq '.technologies[] | select(.risk == "High")'

Batch scan multiple targets:
  for target in site1.com site2.com site3.com; do
    python3 techfinger.py -u https://$target -o json &gt; $target.json
  done

Use with Burp Suite proxy:
  export HTTPS_PROXY="http://127.0.0.1:8080"
  python3 techfinger.py -u https://target.com
